### What I focus on

- **Threat modeling & testing** for REST/GraphQL and microservice boundaries (BOLA/IDOR, authZ gaps, excessive data exposure).
- **Secure API design** — OAuth 2.0 / OIDC usage, scopes & claims, token lifecycle, and least-privilege access patterns.
- **Standards & automation** — OpenAPI/Swagger contracts, schema validation, CI-friendly security checks, and developer-friendly guardrails.
- **Advocacy** — talks, write-ups, and hands-on enablement so builders ship secure APIs without slowing down.
