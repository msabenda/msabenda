## 👨‍💻 About Me

I am an **API Security Specialist and Pentester** focused on helping organizations design, assess, and secure modern API-driven systems.

My work centers around identifying and mitigating risks aligned with the **OWASP API Security Top 10**, including:

- Broken Object Level Authorization (BOLA)
- Broken Authentication
- Excessive Data Exposure
- Server-Side Request Forgery (SSRF)
- Security Misconfiguration
- Unsafe Consumption of APIs

I work closely with engineering teams to integrate security throughout the **Secure Software Development Lifecycle (SSDLC)** through secure design reviews, API penetration testing, threat modeling, and developer-focused security guidance.
