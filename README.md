### 🛰️ API Finder Extension
Author of **API Finder**, a Chrome extension for passive API reconnaissance.

API Finder listens to browser HTTP(S) traffic, summarizes discovered endpoints, and optionally exports findings for authorized security testing. It also includes a local request tester inside the Finder Console for user-initiated endpoint testing.
