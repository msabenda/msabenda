# Msambili Ndaga

**API Security Specialist & Advocate** — Cybersecurity · Tanzania

I work with engineering teams to **design, review, and test APIs** so common failure modes (OWASP API Top 10–style risks) are caught early: broken object level authorization, weak authentication and session handling, excessive data exposure, unsafe consumption of third-party APIs, and gaps between documentation and runtime behavior.

---

## Focus

| Area | Examples |
|------|----------|
| **Assessment & hardening** | Threat modeling for REST/GraphQL surfaces, abuse-case review, authorization and IDOR-style checks |
| **Identity & access** | OAuth 2.0 / OIDC patterns, scopes and claims, token lifecycle, least-privilege API access |
| **Engineering practice** | OpenAPI-driven contracts, validation and schema drift, security checks in CI/CD, pragmatic guardrails for developers |
| **Advocacy** | Talks, technical writing, and hands-on sessions that connect security requirements to how teams actually ship |
